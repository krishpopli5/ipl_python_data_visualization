# IPL Data Visualization using Python

This project explores Indian Premier League (IPL) match data through data analysis and visualizations in a Jupyter Notebook.

## Project Overview

The analysis uses IPL match data to identify patterns in team performance, toss decisions, player achievements, bowling statistics, and match venues.

## Tools and Libraries Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The project uses the `IPL.csv` dataset, which contains IPL match-related information such as teams, winners, toss decisions, player awards, top scorers, bowling figures, venues, and win margins.

## Analysis Performed

- Checked dataset information, size, and missing values
- Identified teams with the most match wins
- Analyzed toss decision trends
- Compared toss winners with match winners
- Analyzed wins by runs and wickets
- Found players with the most Player of the Match awards
- Identified top scorers and leading bowling performances
- Explored the venues that hosted the most matches
- Answered custom questions, including:
  - Highest winning margin by runs
  - Highest individual score
  - Best bowling figures
